# Clipkeep for Android — releases

This repository only hosts release builds (APK files) and release notes for **Clipkeep for Android**.
It contains no source code. New versions are published here automatically.

## Install

1. Open the latest release and download the APK for your phone:
   - `clipkeep-<version>-arm64-v8a.apk` — almost every phone from the last several years
   - `clipkeep-<version>-armeabi-v7a.apk` — older 32-bit phones
   - `clipkeep-<version>-universal.apk` — works everywhere, larger download
2. Open the file on the phone and allow your browser or file manager to install unknown apps when Android asks.
3. Each release lists the SHA-256 of every APK in `SHA256SUMS`.

Once installed, the app checks this page for new versions itself (Settings → About → Check for updates),
verifies the download's checksum and signing certificate, and asks Android to install it.

Use the app only for content you have the right to save (your own posts, personal offline viewing),
and respect creators' rights and the platforms' terms.
